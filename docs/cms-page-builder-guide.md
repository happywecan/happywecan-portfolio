# 首頁區塊式 CMS 操作指南

這份指南說明如何使用網站後台編排首頁。整個流程不需要撰寫 HTML、CSS 或 JavaScript。

## 1. 開啟管理後台

本機開發環境：

```text
http://localhost:3000/login
```

登入後，在左側選單進入「首頁內容」，或直接開啟：

```text
http://localhost:3000/admin/content/home
```

如果頁面自動跳回登入畫面，代表登入憑證已過期，重新登入即可。

## 2. 認識編輯器

首頁編輯器由三個部分組成：

1. **頁面名稱**：後台用來辨識這個頁面。
2. **目前區塊**：依照前台顯示順序由上往下排列。
3. **新增區塊**：選擇一種版型並加入頁面底部。

完成調整後，先按「預覽」檢查尚未發布的畫面，再按「發布首頁」。發布成功後，重新整理公開首頁即可看到結果。離開有未發布變更的頁面時，瀏覽器會提醒。

## 3. 區塊操作

每個區塊上方都有以下操作：

- **排序**：按「上移／下移」調整；桌面也可拖曳區塊。
- **顯示／隱藏**：暫時停止顯示區塊，但保留內容。
- **複製**：在原區塊下方建立一份副本。
- **刪除**：從頁面配置中移除區塊。

刪除或重新排序不會立即影響公開網站，必須按「發布首頁」才會生效。

## 4. 可用區塊

### 完整作品首頁

保留網站目前的完整首頁設計。第一次使用 CMS 時，系統會自動建立這個預設區塊，因此原本首頁不會消失。

如果想逐步改成自由編排，可以先保留它，再於下方加入新區塊測試。確認新配置完成後，再隱藏或刪除完整作品首頁。

### 首頁主視覺

顯示現有主視覺版型。標題可在後台頁面底部的「主視覺內容設定」調整；目前照片與按鈕仍使用固定版型內容。

### 關於我

顯示網站目前固定的定位介紹。

### 技能

顯示網站目前固定的工作方式與工程方法。

### 作品集

顯示網站目前固定的案例展示。此區塊尚未連接後台的作品資料。

### 部落格

顯示網站目前固定的文章入口，連至部落格頁面。

### 聯絡表單

顯示訪客留言表單與聯絡資訊。

### 文字內容

適合放置自我介紹、服務說明、公告或長篇文字，可設定：

- 小標籤
- 標題
- 內容

內容支援簡單 Markdown，例如：

```markdown
## 小標題

這是一般段落，**這段文字會加粗**。

- 第一項
- 第二項
```

請不要輸入 HTML；系統會使用固定版型保持網站一致性。

### 圖文內容

適合展示服務、經歷或單一精選作品，可設定：

- 小標籤
- 標題
- 文字內容
- 圖片網址或上傳圖片
- 圖片替代文字
- 圖片放在左側或右側

圖片替代文字應簡短描述圖片，例如「MES 分析儀表板畫面」，有助於無障礙閱讀。

### 行動呼籲

適合引導訪客聯絡、查看作品或閱讀文章，可設定標題、說明、按鈕文字與連結。

連結範例：

```text
#contact
/portfolio/作品ID
https://example.com
mailto:your-email@example.com
```

### 留白

在兩個區塊之間加入小、中或大型間距。只在版面太擁擠時使用，避免連續加入太多留白。

## 5. 建議的首頁配置

如果想保留目前風格，使用：

```text
完整作品首頁
```

如果想改成容易維護的模組化首頁，可使用：

```text
首頁主視覺
關於我
技能
作品集
文字內容（服務或工作方式）
部落格
行動呼籲
聯絡表單
```

建議一次只調整一至兩個區塊，儲存後在桌面與手機寬度檢查，再繼續下一次修改。

## 6. 圖片使用建議

- 優先使用 JPG、PNG 或 WebP。
- 一般內容圖片建議採用約 4:3 比例。
- 避免上傳過大的原始照片，以免首頁載入過慢。
- 圖片上傳完成後，確認欄位中已出現 `/static/uploads/...` 路徑。
- 正式環境目前使用 VM 儲存空間；重新部署前不要任意刪除 `static/uploads`。

## 7. 發布與復原

「預覽」只在編輯器中顯示未發布內容，不會變更公開首頁。按「發布首頁」後才會更新公開首頁，目前沒有多人審核步驟。

「發布紀錄」保留最近 20 個舊版本，可選擇「復原並發布」；復原也會產生新版本。若別的管理員在你編輯期間發布了新內容，系統會要求重新載入，避免覆蓋對方的修改。

修改前可先複製重要區塊，再隱藏副本。若新內容效果不理想，可以重新顯示副本並刪除新版區塊。

若首頁所有區塊都被隱藏，前台會退回顯示預設的完整作品首頁，避免出現完全空白的頁面。

## 8. 安全與權限

- 公開訪客只能讀取首頁配置。
- 修改與發布必須先登入管理員帳號。
- 登入憑證失效時，後台會要求重新登入。
- 不要把管理員密碼、JWT 或 `.env` 內容貼到公開頁面。
- 自訂按鈕只接受站內路徑、頁面錨點、HTTP(S) 或電子郵件連結。圖文區塊使用圖片時須填寫替代文字。

## 9. 常見問題

### 儲存後前台沒有改變

1. 確認已看到「首頁配置已儲存」提示。
2. 重新整理公開首頁。
3. 確認該區塊不是隱藏狀態。
4. 若仍沒有變化，重新登入後再儲存一次。

### 圖片無法顯示

確認圖片網址完整，或重新使用「上傳」按鈕。站內圖片通常會是：

```text
/static/uploads/檔名.jpg
```

### 拖曳在手機上不好操作

目前拖曳編排較適合使用桌面瀏覽器。手機可以編輯文字，但建議在電腦上調整區塊順序。

### 不小心刪除區塊

如果還沒按「儲存並發布」，重新整理後會恢復上次儲存的配置。如果已經儲存，需要重新新增該區塊並填入內容。

### 如何回到原本首頁

新增一個「完整作品首頁」區塊，將它移到第一個位置，並隱藏其他區塊後儲存即可。

## 10. 開發者資訊

相關程式位置：

```text
frontend/components/admin/PageBuilder.tsx
frontend/components/sections/HomePageRenderer.tsx
frontend/services/pageService.ts
backend-java/src/main/java/com/happywecan/portfolio/page/
```

API：

```text
GET /api/pages/home       公開讀取
PUT /api/pages/home       管理員 JWT 驗證後更新
```

MongoDB collection：

```text
pages
```
